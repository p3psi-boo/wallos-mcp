The root [WTFPL 2.0 license](LICENSE) covers original Wallos MCP project code. It does not replace the terms of dependencies or third-party source material.

## Wallos API documentation

- Upstream application: https://github.com/ellite/Wallos
- Official API documentation: https://api.wallosapp.com/
- Schema root: https://api.wallosapp.com/openapi.yaml
- Checked-in source files: `vendor/wallos/`
- Download URLs, original SHA-256 hashes, and acquisition time: `vendor/wallos/sources.json`
- Generated TypeScript declarations: `src/wallos/generated.d.ts`

The snapshot contains the root document and 24 external endpoint definitions. Local references are rewritten and YAML is normalized. `bundled.yaml` is built from those local files and clears the upstream demo-server list. The generated declarations are derived from the pinned schema snapshot.

Wallos API documentation and its derived declarations retain upstream attribution and applicable terms. The downloaded root specification does not declare an SPDX license. The upstream Wallos application identifies its license as GPL-3.0; see its [license file](https://github.com/ellite/Wallos/blob/main/LICENSE.md). The application source itself is not vendored here.

The PHP behavior reference is pinned to commit `cc9677a67e76ac55c13f373d4c7cc5ca9007079e`. See [that commit's API directory](https://github.com/ellite/Wallos/tree/cc9677a67e76ac55c13f373d4c7cc5ca9007079e/api). Calendar fixtures are generated by this project's offline test utility.
